## 4. Decisions

1. **The site is the superset; the resume augments it.** Everything genuine on the current site stays: all ten roles with their position titles, month-level dates and first-person notes; the high-school and Associate of Arts education entries (the Bachelor's entry is omitted by the owner's decision); the front-end skills in the icon grid; the three projects. The resume document adds the professional summary, the grouped skills, the Auto Data Direct highlights and the Dunkin’ Donuts result line, and becomes the downloadable PDF. Placeholder strings are dropped, never rewritten; a role with no real note shows its positions and dates until the owner adds copy.
2. **Phone number is never published.** Not in JSON, not on the page, not in the PDF. A content test enforces this for JSON; the PDF task strips it before conversion.
3. **One UI library: Bootstrap 5.3 via react-bootstrap.** MUI and Emotion are removed. Dark mode comes from `data-bs-theme="dark"` on `<html>`, which also fixes the card-title contrast bug. Headings use Cormorant SC via `next/font/google`; body text uses Bootstrap's system font stack for readability.
4. **Framework: Next.js 16.3.5 with the Pages Router, React 19.3.0.** No App Router migration. Lint runs through ESLint 9 flat config because `next lint` no longer exists in Next 16. Tests run through the `next/jest` preset.
5. **Package manager: npm only.** `pnpm-lock.yaml` is deleted. `node_modules` is reinstalled with npm.
6. **The resume is the root route.** `/` renders the resume. `/resume` issues a permanent redirect to `/` so existing links keep working. The landing-page hop is removed.
7. **Every section is a component that takes data via props.** Only `pages/*` import `content/*.json`. Tests pass fixtures; no test imports content except the content-validation test.
8. **Portfolio pages become one dynamic route** `pages/portfolio/[slug].jsx` driven by `content/projects.json`, preserving the existing URLs `/portfolio/to-do-list`, `/portfolio/pokedex`, `/portfolio/hangman`. `/portfolio/menu-trainer` is removed.
9. **The carousel is removed.** It carried placeholder slides and 3.5 MB of stock photos and has no equivalent in the resume.
10. **Social links keep all four existing entries** (GitHub, LinkedIn, YouTube, Instagram). To drop one, delete it from `profile.social`.
11. **Site URL** for canonical and Open Graph tags comes from `NEXT_PUBLIC_SITE_URL`, defaulting to Vercel's `VERCEL_PROJECT_PRODUCTION_URL` at build time and to `http://localhost:3000` locally.

## 5. Target structure

```
content/
  profile.json       name, title, location, email, summary, about?, headshot, resumePdf, social[]
  skills.json        [{ category, skills: [{ name, icon }] }]
  experience.json    [{ id, company, positions[], location, start, end, highlights[], notes? }]  newest first
  education.json     [{ id, school, location, credential, major?, start, end, image? }]        newest first
  projects.json      [{ slug, name, summary, demoUrl, image, stack: [{ name, icon }] }]
components/
  iconMap.js         iconFor(key) -> react-icons component, FaCode fallback
  SiteHead.jsx       title, description, canonical, Open Graph, optional JSON-LD
  SectionNav.jsx     sticky navbar with anchors to each section
  SocialLinks.jsx    labelled icon links, target=_blank rel=noopener noreferrer
  Footer.jsx         id="contact": email, social links, copyright
  personJsonLd.js    buildPersonJsonLd(profile, siteUrl)
  resume/HeroSection.jsx        name, title, location, summary, headshot, PDF + email buttons, social
  resume/SkillsSection.jsx      id="skills"
  resume/ExperienceSection.jsx  id="experience", accordion, newest role open
  resume/ProjectsSection.jsx    id="projects", cards linking to /portfolio/[slug]
  resume/EducationSection.jsx   id="education"
pages/
  _app.js            bootstrap css, globals.css, next/font heading font
  _document.js       <Html lang="en" data-bs-theme="dark">
  index.jsx          the resume
  portfolio/[slug].jsx
public/
  David_Daniel_Resume.pdf
  images/headshot.jpg (600x600), aa_grad_photo.jpg and hs_grad_photo.jpg (800x600), 3 project screenshots
styles/globals.css   heading font, skill icon hover, smooth scroll with sticky-nav offset
tests/
  content/content.test.js
  components/*.test.jsx
  pages/home.test.jsx, pages/projectPage.test.jsx
.github/workflows/ci.yml   lint, test, build, audit
eslint.config.mjs, jest.config.js, jest.setup.js
```

Section ids and headings: `skills` "Skills", `experience` "Experience", `projects` "Projects", `education` "Education", `contact` "Contact". Each `<section>` carries `aria-labelledby` pointing at its `<h2>`, so it is a named landmark region. Exactly one `<h1>` per page.

## 6. Non-goals

App Router migration. A CMS or MDX pipeline. A blog. Analytics. Internationalization. TypeScript conversion. Keeping the menu-trainer project. Restyling beyond Bootstrap defaults plus the heading font.

## 7. Acceptance criteria

1. `npm run lint`, `npm test`, `npm run build` all pass on branch `site-refresh`.
2. `npm audit --omit=dev` lists no advisory for `next`.
3. `npm run build` reports static routes `/`, `/404`, `/portfolio/[slug]` (3 paths) and nothing else.
4. With the production server running, a headless browser confirms on `/` and `/portfolio/hangman`, at 1280px and 390px:
   - `document.title` is non-empty and `<meta name="description">` is present;
   - `document.documentElement.lang === 'en'`;
   - no `body body` element;
   - computed color of every `.card-title` is not `rgb(33, 37, 41)`;
   - `document.documentElement.scrollWidth <= clientWidth` (no horizontal overflow);
   - zero `<a>` elements with empty text and no `aria-label`;
   - every `a[href^="http"]` has `target="_blank"` and `rel` containing `noopener`;
   - exactly one `<h1>`.
5. `curl -I /resume` returns a 308 with `location: /`.
6. `curl -I /David_Daniel_Resume.pdf` returns 200 and `pdftotext` of the file contains no `561-629-3906`.
7. `grep -r "561-629-3906"` over the repository (excluding `node_modules`, `.next`) returns nothing.
8. Every string in §3.1 appears verbatim in `content/*.json` (spot-check all nine Auto Data Direct highlights), every real note in §3.2 appears verbatim in `content/experience.json` (spot-check Grande's and Westwood), and no string from §3.3 appears anywhere under `content/`.
